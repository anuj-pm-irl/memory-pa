# Using memory-pa

When someone opens this repo to get started with memory-pa, read `skills/memory-pa/SKILL.md` and follow **Set up memory**. Help them choose and verify a store in the chat. If they already have a working store, use it for capture and recall. Follow the skill for note takers and routines. Ask before opening setup screens and follow **Hand over for sign-in** when credentials are needed.

For changes to the code or docs, use the development setup in [CONTRIBUTING.md](CONTRIBUTING.md). Use fictional notes in the public repo and its tests.
