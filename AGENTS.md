# Using memory-pa

When someone asks to set up or update memory-pa, read `skills/memory-pa/SKILL.md`. For setup, ask one question at a time and do the steps the user approves. Verify the store and run the fictional demo when asked. For updates, follow **Update memory-pa** and verify the existing workspace. Use **Hand over for sign-in** for setup screens and credentials. Use an existing working store for capture and recall.

For changes to the code or docs, use the development setup in [CONTRIBUTING.md](CONTRIBUTING.md). Use fictional notes in the public repo and its tests.
