# README comic

[The menu-card mission](save-ask-answer.gif) tells the story in three panels. Tony asks JARVIS to send a reminder, JARVIS checks the June 7 task, and Happy gets a message about the June 20 dry run. The dialogue and send are fictional. The assignment comes from the archive. [Still version](stark-archive-comic.png) · [Original note](../../examples/workspace/topics/field-kitchen/breakfast-in-a-blackout-2032-06-07.md#source-text)

[The Stark Archive detective board](stark-archive-memory-map.png) uses pinned notes, character stickers, and red thread to show a selection of links. Happy Hogan and Sam Wilson connect to the field kitchen note. James Rhodes connects notes from Tower Access and Roof Garden. [Full Stark Archive](../../examples/workspace/index.md)

The strip uses a classic newspaper-comic rhythm. The first panel sets up the request, the second shows the evidence, and the third delivers the message. Character cues come from Marvel references, with original drawings for this demo.
