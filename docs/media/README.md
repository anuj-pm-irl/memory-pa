# README comic

[Breakfast in a blackout](save-ask-answer.gif) tells the story in three panels. Happy promises to bring the sample cards, Tony asks who’s bringing them, and memory-pa opens the original June 7 note. The dialogue illustrates the workflow. [Still version](stark-archive-comic.png) · [Original note](../../examples/workspace/topics/field-kitchen/breakfast-in-a-blackout-2032-06-07.md#source-text)

[The Stark Archive detective board](stark-archive-memory-map.png) uses pinned notes, character stickers, and red thread to show a selection of links. Happy Hogan and Sam Wilson connect to the field kitchen note. James Rhodes connects notes from Tower Access and Roof Garden. [Full Stark Archive](../../examples/workspace/index.md)

The strip uses a classic newspaper-comic rhythm: setup, jump forward, payoff. The panel captions carry the time jump, the balloons carry the dialogue, and the final panel shows the evidence. Character cues come from Marvel references, with original drawings for this demo. [Peanuts strip archive](https://www.gocomics.com/peanuts) · [Marvel on Iron Man](https://www.marvel.com/articles/movies/iron-man-kevin-feige-jon-favreau-15-anniversary-interview) · [Marvel on Sam Wilson](https://www.marvel.com/articles/comics/psych-ward-captain-america)
