# README illustrations

The [Rainy Robot Club cover](rainy-robot-club.jpg) was created with the built-in ImageGen tool. The [chat GIF](setup-chat.gif) is an illustrated example of setup. The [memory map](memory-map.png) uses the fictional [Rainy Robot Club proposal](../../examples/robot-club.json).

## Cover prompt

```text
Use case: illustration-story
Asset type: landscape illustration for a beginner-friendly open-source GitHub README.
Primary request: a cheerful little Rainy Robot Club helper files a paper note into a folder beside a glowing blue lantern. Show one small rounded robot with a friendly expressive face, one paper note with abstract unreadable lines, and a short row of folders. Add two tiny raindrops outside a simple window for atmosphere.
Style: polished editorial illustration with simple cut-paper shapes, clean navy outlines, subtle paper texture, and a bit of depth. Endearing and readable at a small size.
Composition: wide landscape scene with the objects clustered around one small desk in the center, balanced negative space, and tidy edges. Use most of the width. Light periwinkle background, rich blue lantern and folders, warm amber accents.
Constraints: no lettering, logos, borders, app chrome, or watermark. Fictional scene.
```
